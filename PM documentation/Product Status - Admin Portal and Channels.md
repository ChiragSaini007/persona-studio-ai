# Product Status: Admin Portal and Channels (10 Oct 2026)

## Two products
- **Fanline**: creator self-serve. Unlimited avatars per creator. Instagram connect is simulated (real auth later).
- **Admin Portal**: Ops-only. Admin can approve and publish; Ops can build, test and pause.

## Rules that never change
- Consent first. A managed (Ops-built) avatar goes live only when: rights confirmed (who, when, one-line reference, territories IN/US/ROW), admin approval, and the fan is in an allowed territory.
- Agreements are signed outside the tool. The tool records a rights confirmation, not contracts.
- Example avatars (Shah Rukh Khan reference record) can never be published.
- Fans are always told they are talking to an AI. Editing reviewed fields resets approval and pauses the avatar.
- Main guardrails can never be weakened by a genre mode.

## One persona, many genre modes
Each avatar has a main persona plus adaptable modes (Action, Romance, Comedy, Horror). A mode overlays tone only.
