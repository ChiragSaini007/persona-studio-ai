# Persona Studio AI Production Setup

## Required Services

1. Supabase project
2. OpenAI API key
3. Stripe account for paid conversations

## Database

Run `supabase/schema.sql` in your Supabase SQL editor.

This creates:

- `personas`
- `conversations`
- `messages`

## Environment Variables

Use `.env.example` as the source of truth.

Required for real creator/fan testing:

- `SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_URL`
- `SUPABASE_SERVICE_ROLE_KEY`
- `SUPABASE_ANON_KEY`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- `OPENAI_API_KEY`
- `OPENAI_MODEL=gpt-5-mini`

Required for paid chat testing:

- `STRIPE_SECRET_KEY`
- `STRIPE_WEBHOOK_SECRET`
- `STRIPE_CURRENCY`

## Current Production Behavior

- Creator publishes persona from `/creator`.
- Persona is saved to Supabase when Supabase env vars are configured.
- Fan page `/p/[handle]` loads the live persona by handle.
- Fan conversations and messages are stored in Supabase.
- Replies are generated by OpenAI when `OPENAI_API_KEY` is configured.
- `gpt-5-mini` is the default production model for persona quality and cost balance.
- Guardrail and moderation hits are logged as flagged messages.
- Supabase Auth is used for creator signup/signin and fan signup/signin.
- First production test is free fan access. Stripe can be re-enabled later for paid chat.
