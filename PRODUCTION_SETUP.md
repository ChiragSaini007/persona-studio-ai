# Persona Studio AI Production Setup

## Required Services

1. Supabase project
2. OpenAI API key
3. Stripe account for paid conversations

## Database

Run `supabase/schema.sql` in your Supabase SQL editor.

This creates:

- `personas`
- `conversations`
- `messages`

## Environment Variables

Use `.env.example` as the source of truth.

Required for real creator/fan testing:

- `SUPABASE_URL`
- `SUPABASE_SERVICE_ROLE_KEY`
- `OPENAI_API_KEY`

Required for paid chat testing:

- `STRIPE_SECRET_KEY`
- `STRIPE_WEBHOOK_SECRET`
- `STRIPE_CURRENCY`

## Current Production Behavior

- Creator publishes persona from `/creator`.
- Persona is saved to Supabase when Supabase env vars are configured.
- Fan page `/p/[handle]` loads the live persona by handle.
- Fan conversations and messages are stored in Supabase.
- Replies are generated by OpenAI when `OPENAI_API_KEY` is configured.
- Guardrail and moderation hits are logged as flagged messages.
- Stripe checkout is available for paid-per-conversation personas when Stripe env vars are configured.

## Still Needed Before Real Public Launch

- Real creator authentication and account ownership checks
- Stripe webhook signature verification and paid entitlement reconciliation
- Row-level security policies or a separate authenticated API gateway
- Creator dashboard backed by database aggregation
- File upload storage for PDFs, transcripts, and larger content batches
- Abuse limits, rate limits, and audit logs
